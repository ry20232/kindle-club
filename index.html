A lightweight hangout for Kindle and tablet browsers. Accounts, pixel-art profiles, live chat, multiplayer games, and member moderation.

Local demo mode: the mini-games work on this device. Shared chat, accounts, multiplayer, and moderation need a Firebase project, its web-app settings in index.html, and the rules from firebase-rules.json published in Firebase Console. The setup guide explains each step.

🛡️ Moderation

Staff only

Promote trusted club members, apply timeouts, or ban an account. The site owner cannot be banned or timed out.

Moderator tools appear for approved staff accounts only.

🔒 Site ownership

Only the site owner can edit the website's code through GitHub. There is no in-site button for visitors to update the website. Moderators can only moderate club members.
